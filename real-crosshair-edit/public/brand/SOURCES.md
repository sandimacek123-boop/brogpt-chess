Notes

- **App-icon lockup.** The coloured app icon (white rounded square, symbol in a blue→violet gradient) and the wordmark "Real" come from the official lockup image the owner supplied.
  - The gradient is sampled from that image: `#A8AEF8` → `#4463F0`, top to bottom.
  - The symbol sits at 73 % of the icon width.
  - The wordmark is set in Montserrat SemiBold with ≈ 0.1 em tracking.
  - The symbol geometry is the official SVG, never redrawn or distorted.
- **Fonts.** The site's interface font is Geist, with Geist Mono for technical labels.
- **Left out on purpose.** The site's "account manager" screenshot shows Roblox usernames and IDs, so it isn't used.
- **Links.** Discord invite `discord.gg/projectreal` was verified with the Discord invite API: server "Real", vanity code `projectreal`.
